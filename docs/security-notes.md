# Безопасность релиза

Дата: 18 ноября 2026 года. Сайт публикуется как статические файлы Cloudflare Pages. Production не запускает Node.js, Vite dev или Vite preview.

## Результаты audit

Полный `npm audit`: пять записей **high**, код выхода 1. `npm audit --omit=dev`: **0 уязвимостей**, код выхода 0.

| Пакет в lock-файле | Версия | Причина отметки | В браузерной сборке |
| --- | --- | --- | --- |
| picomatch | 4.0.7 | ReDoS при обработке специально составленных glob-шаблонов | нет |
| fdir | 6.5.0 | Зависит от picomatch | нет |
| tinyglobby | 0.2.17 | Зависит от fdir и picomatch | нет |
| vite | 8.3.8 | Зависит от tinyglobby и picomatch | нет |
| @vitejs/plugin-react | 6.3.0 | Использует Vite | нет |

Это одна первичная уязвимость с транзитивными отметками: [GHSA-fc5q-39xc-vjpf / CVE-2026-112366](https://github.com/advisories/GHSA-fc5q-39xc-vjpf). На дату проверки затронуты версии picomatch ≤4.0.7; исправленная версия не опубликована. Доступная версия в npm — 4.0.7. `audit fix --force` предлагает понижение основных версий Vite/React-плагина, поэтому не применён. Зависимости и lock-файл не изменены.

## Достижимость

`npm run check:production-deps` проверяет реальные модули всех JS-частей сборки, включая ленивые части и workers. Проверено 76 уникальных модулей: граф страницы — 71, отдельные графы workers подписи и редактора — 10 и 8 модулей; общие модули считаются один раз. Все пять пакетов отсутствуют. В runtime найдены React, React DOM, scheduler и MediaPipe tasks-vision. Отчёт создаётся локально: `test-results/production-module-audit.json`. Пустой граф страницы или workers считается ошибкой, а не успешной проверкой.

Уязвимый glob-парсер не достижим через загруженное на сайте фото или браузерные настройки. Он остаётся риском среды сборки при обработке недоверенных glob-шаблонов/конфигурации. Не передавайте произвольные шаблоны внешних пользователей в build tools, не публикуйте dev/preview и рассматривайте сборку недоверенных PR как выполнение кода.

После появления исправленной совместимой версии обновите lock-файл, повторите audit, `npm test`, build и проверку графа. Не заменяйте этот вывод только поиском слова picomatch в минифицированном JS.

## Изображения и локальные данные

- Приложение не отправляет пользовательские фото, подписи или их содержимое в аналитику.
- Файлы `tests/fixtures/selfies/`, разметка, локальный HTML с фото, отчёты и `test-results/` исключены из Git. Их нельзя публиковать или добавлять принудительно.
- `public` и `dist` не предназначены для личных фото, `.env` или ключей. `.env*` исключены из Git.
- Калибровка запускает только локальный сервер 127.0.0.1. Фото передаются локальному браузеру через управление тестом; HTTP-отправки и внешние запросы блокируются.
- CSP сохранена. Для новых казахских страниц применён тот же `no-transform`, чтобы хостинг не подставлял сторонний скрипт в HTML.
- `security.txt` содержит существующий контакт info@nexcel.kz, срок действия до 01.11.2027, языки ru/kk и собственный canonical. Доступность самого почтового ящика не проверялась.

Проверки на реальных iPhone, Android и Samsung и проверка переводов носителем остаются незавершёнными. Эмуляция браузера и Lighthouse не являются доказательством этих проверок.
