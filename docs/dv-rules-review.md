# Сверка правил DV

Проверено 18 ноября 2026 года по [официальной странице Photo Requirements](https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos.html), разделам общих требований, Diversity Visa и самостоятельной съёмки.

| Пункт карточек | Статус | Официальное требование |
| --- | --- | --- |
| Размер | подтверждено | 600 × 600 px, квадрат |
| Размер файла | подтверждено | Не более 240 kB |
| Формат | подтверждено | JPEG (.jpg) |
| Цвет | подтверждено | Цветное фото |
| Доля головы | подтверждено | 50–69% высоты от нижней точки подбородка до макушки |
| Срок съёмки | подтверждено | Последние 6 месяцев, актуальная внешность |
| Фон | подтверждено | Белый или почти белый, однотонный |
| Положение | подтверждено | Анфас, прямо к камере |
| Выражение | подтверждено | Нейтральное, оба глаза открыты |
| Очки | подтверждено | Не допускаются; редкое медицинское исключение со справкой |
| Головные уборы | подтверждено | Исключение для ежедневного религиозного ношения; лицо видно, без теней |
| Обработка и ретушь | подтверждено | Цифровые изменения внешности не допускаются |
| Одежда и аксессуары | подтверждено | Повседневная одежда; ограничения для униформы и наушников |
| Сканирование | подтверждено | Отпечаток 51 × 51 мм, 300 ppi |
| Собеседование | подтверждено | Два одинаковых отпечатка 51 × 51 мм |

Явных расхождений в карточках не найдено; числа и существующие переводы не изменены. Мягкое предупреждение об обработке сохранено, рядом с ним добавлена официальная ссылка. Добавлена строка «Правила могут меняться, сверяйтесь на travel.state.gov».

Соответствие конкретной фотографии, допустимость конкретной правки и решение принимающего органа **не проверены**. Казахский перевод — **на проверку носителем**.
